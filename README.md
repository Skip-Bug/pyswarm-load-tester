# 🐝 PySwarm — Universal Load Testing Tool

Портативный, кроссплатформенный инструмент для нагрузочного тестирования REST API с удобным веб-интерфейсом и графиками в реальном времени.

**Один файл. Три режима. Все ОС.**

---

## 🚀 Особенности

- **Universal:** Работает как готовый `.exe` (Windows), бинарник для Linux/macOS, через `pip install` или в Docker.
- **Три режима работы:**
  - 🏠 **Локальный** — всё в одном процессе (мастер + воркеры).
  - 👑 **Мастер** — управляет распределённым тестом, отдаёт UI и данные.
  - ⚙️ **Воркер** — подключается к мастеру и генерирует нагрузку (автоматически скачивает JSON с мастера).
- **Real-time Web UI:** Живые графики RPS, пользователей и ошибок, а также статистика задержек (p50, p95, p99) по каждому эндпоинту.
- **Fast & Memory-Safe:** Использует `locust` (FastHttpUser). Встроенный **Watchdog** автоматически остановит тест, если RAM сервера достигнет 95% (настраивается).
- **Zero dependencies:** В стандартной сборке не требует установки Python или Docker.

## 📦 Установка и запуск

### Вариант 1: Готовые бинарники (Рекомендуется)

Скачайте `pyswarm-windows.exe`, `pyswarm-linux` или `pyswarm-macos` со [страницы релизов](https://github.com/Skip-Bug/PySwarm/releases).

**Windows:**
```cmd
pyswarm-windows.exe
```

**Linux/macOS:**
```bash
chmod +x pyswarm-linux
./pyswarm-linux
```

### Вариант 2: Через Python (pip)

Если у вас установлен Python 3.10+:

```bash
pip install .
pyswarm
```

### Вариант 3: Из исходников

```bash
git clone https://github.com/Skip-Bug/PySwarm.git
cd PySwarm
python -m venv .venv
# Windows: .venv\Scripts\activate | Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python pyswarm.py
```

### Вариант 4: Docker

```bash
# Запуск в локальном режиме (всё внутри контейнера)
docker compose up -d master

# Распределённый запуск (мастер + 3 воркера)
docker compose up -d --scale worker=3
```

## 🎮 Режимы работы

### 🏠 Локальный режим (по умолчанию)

Запустите без флагов — откроется веб-интерфейс на `http://127.0.0.1:8000` и поднимется один локальный воркер. Этого достаточно для 95% задач.

```bash
python pyswarm.py
```

**Совет:** Для локального запуска нескольких воркеров на одной машине (использовать все ядра) задайте переменную окружения:

```bash
# Windows
set LOCUST_WORKERS=4

# Linux / macOS
export LOCUST_WORKERS=4
```

Затем просто запустите `pyswarm` — поднимется 4 воркера.

### 👑 Режим Мастера

Запускается на главном сервере. Открывает UI на порту `8000` и ждёт подключения воркеров.

```bash
python pyswarm.py --master
```

### ⚙️ Режим Воркера

Запускается на машинах с нагрузкой. Подключается к мастеру и автоматически скачивает JSON-конфигурацию.

```bash
python pyswarm.py --worker --master-host 192.168.1.100
```

## 💡 Как запустить тест

1. **Целевой URL** — адрес сервера для нагрузки (например, `http://192.168.1.10:8080`).
   > ⚠️ Не указывайте `127.0.0.1:8000` — это сам PySwarm!

2. **Токен** — Bearer-токен для авторизации (опционально).

3. **Параметры нагрузки:**
   - **Пользователи** — кол-во одновременных виртуальных юзеров (до 2000).
   - **Скорость** — юзеров в секунду (до 500).
   - **Длительность** — секунд (от 5 до 7200).
   - **Задержка** — пауза между запросами одного юзера (сек).

4. **Режим контура:**
   - 🔵 **Закрытый** — юзер отправляет один запрос и уходит.
   - 🟠 **Открытый** — юзер работает непрерывно с заданной скоростью.

5. **Папка с JSON** — выберите папку с `.json` файлами запросов через веб-интерфейс.

6. Нажмите **«Запустить тест»**.

## 📝 Формат JSON

Загрузите папку с `.json` файлами через веб-интерфейс. Каждый файл — массив запросов:

```json
[
  {
    "method": "GET",
    "url": "/api/users/1",
    "headers": { "Accept": "application/json" }
  },
  {
    "method": "POST",
    "url": "/api/orders",
    "body": { "item_id": 5, "quantity": 2 }
  }
]
```

Программа автоматически подставит целевой URL из настроек в UI.

## 🛠 Сборка бинарника (для разработчиков)

Для сборки standalone-файла используется PyInstaller. Файл `chart.min.js` должен лежать рядом с `pyswarm.py`.

```bash
pip install pyinstaller

# Windows (точка с запятой)
pyinstaller --onefile --name pyswarm --add-data "chart.min.js;." pyswarm.py

# Linux/macOS (двоеточие)
pyinstaller --onefile --name pyswarm --add-data "chart.min.js:." pyswarm.py
```

Готовый файл появится в папке `dist/`.

## ⚙️ Настройки защиты

Параметры находятся в `pyswarm.py`:

| Параметр                    | По умолчанию | Описание                              |
| --------------------------- | ------------ | ------------------------------------- |
| `MAX_SYSTEM_MEMORY_PERCENT` | `95%`        | Остановить тест при загрузке RAM      |
| `MAX_LOCUST_PROCESS_MEM_MB` | `2048 МБ`    | Остановить, если процесс Locust съел > 2 ГБ |
| `MAX_UPLOAD_SIZE_MB`        | `50 МБ`      | Максимальный размер загружаемого JSON |

## 🐳 Docker

### Запуск

```bash
docker compose up -d --build
```

Откройте: **http://127.0.0.1:8000**

### Масштабирование

```bash
docker compose up -d --scale worker=4
```

### Тестирование локальных сервисов

Если сервис работает на вашем компьютере (не в Docker), указывайте:

```
http://host.docker.internal:8080
```

Иначе воркеры будут стучаться сами в себя.

## ⚡ Сравнение режимов

| Фича            | Локальный (.exe / pip)    | Docker (Master/Worker)       |
| --------------- | ------------------------- | ---------------------------- |
| Нужен Python    | ❌ Нет (в бинарнике)      | ❌ Нет (только Docker)       |
| Нужен интернет  | ❌ Нет                     | ❌ Нет                       |
| Масштабирование | 1 машина, до 2000 юзеров  | Master/Worker, много машин  |
| Простота        | ✅ Один файл               | Требует Docker               |
| Для стенда      | ✅ Идеально                | Для продакшена / пиковых нагрузок |
