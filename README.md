# 🐝 PySwarm

Портативный инструмент для нагрузочного тестирования REST API с удобным веб-интерфейсом.

Два режима работы:

- **Standalone** (`pyswarm.exe`) — один файл, не нужен Python/Docker/интернет.
- **Docker** — для продакшена, с архитектурой Master/Worker и масштабированием.

---

## 🚀 Особенности

- **FastAPI** для бэкенда и раздачи дашборда.
- **Locust** (FastHttpUser) для генерации высокой нагрузки.
- **WebSocket + Chart.js** — живые графики в реальном времени.
- **Архитектура Master/Worker** (Docker) — масштабирование на все ядра.
- **Память-сейв**: встроенный watchdog останавливает тест при переполнении RAM (85% / 2 ГБ).
- **Динамическая конфигурация**: задержки, токены, лимиты — прямо из UI.
- **Загрузка JSON-файлов**: загрузите папку с запросами и тестируйте.

## 📦 Режим: Standalone (.exe)

### Сборка

```bash
pip install pyinstaller
pyinstaller --onefile --name pyswarm pyswarm.py
```

Готовый файл появится в `dist/pyswarm.exe`.
Можно скачать [тут](https://github.com/Skip-Bug/PySwarm/releases/tag/v1.0-standalone)
### Запуск

1. Положите `pyswarm.exe` в любую папку.
2. Создайте подпапку для JSON-файлов с запросами (например, `json_data/`).
3. Дважды кликните по `pyswarm.exe` — откроется консоль. **Не закрывайте её**.
4. Откройте браузер: **http://127.0.0.1:8000**

### Как запустить тест

1. **Целевой URL** — адрес сервера для нагрузки (например, `http://192.168.1.10:8080`).
   > ⚠️ Не указывайте `127.0.0.1:8000` — это сам PySwarm!
2. **Токен** — Bearer-токен для авторизации (опционально).
3. **Параметры нагрузки**:
   - **Пользователи** — кол-во одновременных виртуальных юзеров (до 2000).
   - **Скорость** — юзеров в секунду (до 500).
   - **Длительность** — секунд (от 5 до 7200).
   - **Задержка** — пауза между запросами одного юзера (сек).
4. **Режим контура**:
   - 🔵 **Закрытый** — юзер отправляет один запрос и уходит.
   - 🟠 **Открытый** — юзер работает непрерывно с заданной скоростью.
5. **Папка с JSON** — выберите папку с `.json` файлами запросов.
6. Нажмите **«Запустить тест»**.

### Результаты

- Графики RPS, пользователи, ошибки — в реальном времени.
- Таблица задержек: p50, p90, p95 по каждому эндпоинту.
- После теста в папке `tmp/` появятся CSV-файлы со статистикой.

### Остановка

- Кнопка **«Остановить»** в браузере.
- Или закройте консольное окно.

## 🐳 Режим: Docker

### Запуск

```bash
docker compose up -d --build
```

Откройте: **http://127.0.0.1:8000**

### Остановка

```bash
docker compose down
```

### Масштабирование

Запустите больше воркеров для увеличения нагрузки:

```bash
docker compose up -d --scale locust_worker=4
```

### Тестирование локальных сервисов

Если сервис работает на вашем компьютере (не в Docker), указывайте:

```
http://host.docker.internal:8080
```

Иначе воркеры будут стучаться сами в себя.

## 📝 Формат JSON-файлов

Загрузите папку с `.json` файлами. Каждый файл — массив запросов:

```json
[
  {
    "method": "GET",
    "url": "/api/users/1",
    "headers": { "Accept": "application/json" }
  },
  {
    "method": "POST",
    "url": "/api/orders",
    "body": { "item_id": 5, "quantity": 2 }
  }
]
```

Программа автоматически подставит целевой URL из настроек.

## 🔧 Настройки защиты (pyswarm.py)

| Параметр                    | Значение | Описание                            |
| --------------------------- | -------- | ----------------------------------- |
| `MAX_SYSTEM_MEMORY_PERCENT` | 85%      | Остановить тест при загрузке RAM    |
| `MAX_LOCUST_PROCESS_MEM_MB` | 2048 МБ  | Остановить, если Locust съел > 2 ГБ |
| `MAX_UPLOAD_SIZE_MB`        | 50 МБ    | Макс. размер загружаемого JSON      |

## ⚡ Быстрая сравнительная таблица

| Фича            | Standalone (.exe)           | Docker                             |
| --------------- | --------------------------- | ---------------------------------- |
| Нужен Python    | ❌ Нет                      | ❌ Нет (только Docker)             |
| Нужен интернет  | ❌ Нет (кроме Chart.js CDN) | ❌ Нет                             |
| Масштабирование | 1 машина, 1 процесс         | Master/Worker, много машин         |
| Макс. юзеры     | 2000                        | Без ограничений (зависит от машин) |
| Сборка          | PyInstaller                 | docker compose                     |
| Для стенда      | ✅ Идеально                 | Для продакшена                     |
